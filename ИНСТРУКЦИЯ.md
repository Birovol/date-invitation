# Инструкция по запуску и настройке

## Открыть сайт

Откройте `index.html` в браузере. Сборка и зависимости не нужны. GIF-стикеры и шрифт Comfortaa загружаются из интернета; при недоступности GIF сайт покажет встроенную SVG-анимацию.

## Опубликовать через GitHub Pages

1. Откройте репозиторий и перейдите в **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и папку `/(root)`, затем нажмите **Save**.
4. Дождитесь публикации. Для репозитория `Birovol/date-invitation` адрес сайта будет `https://birovol.github.io/date-invitation/`.

После обновления файлов GitHub Pages автоматически опубликует новую версию.

## Уведомления в Telegram

Сайт отправляет `{ date, time, place, food }` на URL из `APPS_SCRIPT_WEBHOOK` в `index.html`. Сам Telegram-токен остаётся на стороне Google Apps Script и никогда не должен попадать в HTML или публичный репозиторий.

### Создать бота и узнать chat ID

1. Создайте бота через [@BotFather](https://t.me/BotFather), отправьте ему `/start` и напишите любое сообщение.
2. Создайте проект на [script.google.com](https://script.google.com/).
3. В **Project Settings → Script properties** добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Пока chat ID неизвестен, сначала добавьте только токен.
4. Добавьте и запустите функцию ниже. Разрешите запрошенный доступ и откройте журнал выполнения. В выводе найдите `message.chat.id` для сообщения боту:

```javascript
function logChatId() {
  const token = PropertiesService.getScriptProperties().getProperty("TELEGRAM_BOT_TOKEN");
  const response = UrlFetchApp.fetch(`https://api.telegram.org/bot${token}/getUpdates`);
  console.log(response.getContentText());
}
```

5. Добавьте найденный ID как свойство `TELEGRAM_CHAT_ID`.

### Добавить обработчик Telegram

В редакторе Apps Script вставьте:

```javascript
function doPost(e) {
  const properties = PropertiesService.getScriptProperties();
  const token = properties.getProperty("TELEGRAM_BOT_TOKEN");
  const chatId = properties.getProperty("TELEGRAM_CHAT_ID");
  const data = JSON.parse(e.postData.contents);

  const [year, month, day] = data.date.split("-").map(Number);
  const date = new Date(year, month - 1, day).toLocaleDateString("ru-RU", {
    day: "numeric",
    month: "long",
    year: "numeric"
  });
  const text = [
    "Новое подтверждение встречи",
    `Дата: ${date}`,
    `Время: ${data.time}`,
    `Место: ${data.place}`,
    `Еда: ${data.food}`
  ].join("\n");

  const response = UrlFetchApp.fetch(
    `https://api.telegram.org/bot${token}/sendMessage`,
    {
      method: "post",
      contentType: "application/json",
      payload: JSON.stringify({ chat_id: chatId, text }),
      muteHttpExceptions: true
    }
  );

  if (response.getResponseCode() !== 200) {
    throw new Error(response.getContentText());
  }
  return ContentService.createTextOutput("ok");
}
```

### Опубликовать веб-приложение и подключить сайт

1. В Apps Script нажмите **Deploy → New deployment** и выберите тип **Web app**.
2. Выберите выполнение от своего аккаунта и доступ **Anyone**, затем нажмите **Deploy**. Это нужно, чтобы сайт мог вызвать обработчик без пользовательского входа.
3. Скопируйте URL веб-приложения и задайте его в `index.html`:

```javascript
const APPS_SCRIPT_WEBHOOK = "URL_ВАШЕГО_WEB_APP";
```

4. Опубликуйте обновлённый `index.html` и пройдите приглашение до финального экрана. Проверьте чат с ботом и раздел **Executions** в Apps Script.

Браузерный запрос использует `no-cors`, поэтому страница не может прочитать ответ Apps Script. Если сообщение не пришло, ориентируйтесь на журнал **Executions** и ошибки вызова Telegram API.

## Безопасность Telegram-токена

Если токен когда-либо попал в HTML, сообщение, скриншот или публичный репозиторий, отзовите его через `/revoke` в @BotFather и создайте новый. Храните токен только в **Script properties** Google Apps Script. Не загружайте в репозиторий файлы с токенами. URL веб-приложения будет виден посетителям сайта, поэтому не передавайте через него чувствительные данные.
